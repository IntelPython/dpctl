Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Selects devices matching a filter selector string.

The string is a comma-separated list of filters, each of the form ``backend:device_type:device_num`` with every component optional and in any order. ``device_num`` counts devices from ``sycl::device::get_devices()`` that match the filter's backend and device type. Matching devices are scored by ``sycl::default_selector_v``.

Throws ``std::invalid_argument`` if the string is malformed.
